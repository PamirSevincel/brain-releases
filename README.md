# Brain releases

Installers and update files for **Brain**, a private desktop app that builds an
understanding of your Obsidian notes on your own computer.

This repository holds release files only. The Brain app checks it for updates; every
update is signed, and Brain refuses any file whose signature doesn't match.

## Download

Open the [latest release](https://github.com/PamirSevincel/brain-releases/releases/latest)
and download the installer for your computer:

- `BrainSetup-x64.exe` for most Windows PCs (Intel or AMD);
- `BrainSetup-arm64.exe` for Windows on ARM (Snapdragon and similar).

Not sure? Settings → System → About → "System type" says "x64-based" or "ARM-based".

Windows may warn that the installer is from an unknown publisher: choose
**More info → Run anyway**.
